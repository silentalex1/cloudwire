CloudWire DNS Client

Query domains using CloudWire's custom DNS infrastructure

How to Use CloudWire DNS

CloudWire runs a custom DNS infrastructure that you can query in multiple ways:

DNS-over-HTTPS (DoH)

  • Query via browser: https://cloudwire.onrender.com/doh/dns-query?name=example.com&type=A
  • Use in applications with DoH support
  • Works everywhere, no special configuration

Command Line (dig)

  • UDP: dig @cloudwire.onrender.com -p 5353 example.com
  • TCP: dig @cloudwire.onrender.com -p 5354 +tcp example.com

API Integration

  • GET: /api/doh/resolve/example.com?type=A
  • Stats: /api/doh/stats
  • Logs: /api/doh/query-log
